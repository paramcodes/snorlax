# Visual Design System: Snorlax

## Brand Identity & Palette
- **Brand Name**: Snorlax (Green Forest Theme)
- **Primary Green (Duolingo-inspired / Forest)**: `#2B8A3E` (Tailwind `emerald-700` / custom `--color-brand`)
- **Accent Green**: `#40C057` (`emerald-500`)
- **Background Surface**: `#1A1D21` (Slack-like rich dark / `#F8F9FA` light mode)
- **Neutral Dark**: `#212529`
- **Neutral Light**: `#F1F3F5`
- **Border**: `#DEE2E6` / `#343A40`

## Screen States & Blueprint
- **Loading Skeleton**: Shimmer loaders for channel lists and message streams.
- **Empty States**: Friendly prompts when a channel has no messages or when no workspace is selected.
- **Error States**: Inline banner alerts with retry action.
- **Active / Unread / Mention**: Bold channel names for unread, red badge for @mentions.
