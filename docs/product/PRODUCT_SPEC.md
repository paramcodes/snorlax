# Product Specification: Snorlax Team Collaboration MVP

## Overview
Snorlax is a browser-first, Slack-inspired team collaboration platform built with an original brand identity and Duolingo-green-led visual system. 

## Prioritized User Journeys
1. **Account Registration & Authentication**: User signs up with email/password, confirms profile name and avatar.
2. **Workspace Management**: User creates a workspace, invites teammates via invite links, and switches between workspaces.
3. **Channel Collaboration**: User creates public and private channels, browses channel lists, and joins discussions.
4. **Durable Live Messaging**: User sends messages, edits/deletes messages, reacts with emojis, and replies in threaded conversations.
5. **Signals & Search**: Unread badges, @mention alerts, and permission-aware full-text search across allowed channels.
6. **Attachments & Polish**: File uploads with secure RLS-backed storage, keyboard navigation, and responsive mobile/desktop layouts.

## Explicitly Deferred
- Audio/video huddles, enterprise SSO, external guest federation, workflow automation, native mobile apps, end-to-end encryption.
